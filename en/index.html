Site 3D modeling and analysis

Pick a site and get 3D terrain and 2D analysis drawings. A free plugin for Rhino, SketchUp and Blender.

I built this as a student to make my own work easier, then cleaned it up to share.

How to install GitHub
  • Rhino 8
  • SketchUp 2022+
  • Blender 4.2+
  • Windows, macOS

Install

  1. Open Package Manager

    Type in the Rhino command line

    PackageManager

  2. Install Gorani

    Search for Gorani and press Install

  3. Restart Rhino

    The plugin loads after a restart.

  4. Open the panel

    Type in the command line

    Gorani

  1. Open Extension Warehouse

    Menu Extensions > Extension Warehouse

  2. Install Gorani

    Search for Gorani and press Install

  3. Open the panel

    Menu Extensions > Gorani, or the gorani button on the toolbar

  1. Open Get Extensions

    Menu Edit > Preferences > Get Extensions. Allow online access the first time.

  2. Install Gorani

    Search for Gorani and press Install

  3. Open the panel

    Press N in the 3D view, then Gorani > Open panel in the sidebar. The panel opens in a browser tab.

The first run in a new area takes a little longer while it downloads data. If something breaks, please leave a note in GitHub Issues.

How it works

The panel opens next to your modeling window. The default options are fine to start with.

  1. 1Pick a site and range

    Click parcels on the map or draw an area, then set the range. Search by address or parcel number. Outside Korea it uses OpenStreetMap data.

  2. 2Make the 3D model

    Buildings, roads, terrain and water go into the open document on separate layers. Building heights come from floor counts.

  3. 3Make the 2D set

    The basemap (.ai), analysis maps and tables (CSV) are saved in 2D/ inside the result folder result/site_date/.

It's free. If it helped, a sponsorship is welcome.
