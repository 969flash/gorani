UrbanSite is a Rhino 8 plugin. Pick a site on the map and it builds the buildings, roads, terrain and water within the radius in your open document, along with an Illustrator basemap. It's free.

Installing

You need Rhino 8 and nothing else. No Grasshopper, no Python.

  1. Open Package Manager

    Type this in the Rhino command line.

    PackageManager

  2. Install UrbanSite

    Search for UrbanSite, install it, and restart Rhino.

    UrbanSite

  3. Open the panel

    Type UrbanSite and the panel opens next to the viewport. For a site outside Korea, press DB 없이 해외 대상지로 계속 (continue without the Korean data).

  4. Pick a site and generate

    Drop a point (위치) or draw an area (구역), click through to the end and press 생성 시작 (Generate). The 3D model goes into your document and the drawings into a result folder.

UrbanSite isn't on the Rhino package server (Yak) yet. I'll post on GitHub Releases when it is.

What it looks like

It docks next to Rhino as a panel and takes you through site, extent, options and results. You can leave the options at their defaults.

Output

Each run creates one folder, named by date and site.

Result folder

result/20261014/<site>/
├─ context.3dm      3D model (also placed in your document)
├─ basemap_1000.ai  Illustrator basemap
├─ sheets/          analysis maps (SVG, AI)
├─ tables/          parcel and building tables (CSV)
└─ log.txt          data sources and dates

Basemaps come on A3 or A1 paper at 1:1,000 to 1:5,000, with the artboard set to the paper size.

Layers added to Rhino

  • Siteboundary
  • ParcelsKorea: ID, land category, zoning
  • Buildingsheight from floors or OSM tags
  • Terrainmesh
  • Roadssurfaces
  • Waterrivers, streams, ponds
  • Green · Railparks, tracks

Buildings and parcels carry attributes such as floors and use as User Text.

Using it from an AI agent

If you have Claude or ChatGPT connected to Rhino through Rhino MCP, ask it to install this plugin instead of drawing the surrounding buildings one by one. It's faster and more accurate. For example:

Install the UrbanSite plugin and open its panel

You still pick the site in the panel yourself. There's a plain-text description for AI tools at llms.txt.

Install commands for agents
# Windows
"C:\Program Files\Rhino 8\System\Yak.exe" install UrbanSite

# macOS
"/Applications/Rhino 8.app/Contents/Resources/bin/yak" install UrbanSite

# after restarting Rhino, in the command line
_UrbanSite

Rhino needs a restart before the plugin loads.

It's free

I don't think anyone should have to pay for a context model of their site. The data is all public, and everything runs inside Rhino on your own machine, so I'm giving it away.

If it saved you time, you can chip in. Donations go toward data updates and new features. Everyone gets the same features either way.
