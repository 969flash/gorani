Install with one search

All you need is Rhino 8. No other software, no Python packages, no Grasshopper definitions.

  1. Open Package Manager

    Type this in the Rhino command line.

    PackageManager

  2. Install UrbanSite

    Search for UrbanSite, install it, then restart Rhino.

    UrbanSite

  3. Open the panel

    Type UrbanSite. The panel docks next to Rhino. For a site outside Korea, press DB 없이 해외 대상지로 계속 (continue without the Korean database).

  4. Pick and generate

    Drop a point (위치) or draw an area (구역), step through extent and options, then press 생성 시작 (Generate). The 3D lands in your document; drawings land in a folder.

UrbanSite is not on the Rhino package server (Yak) yet. Watch GitHub Releases for the launch.

What you get

Each run fills one folder, named by date and site. Take it straight to the kickoff meeting, the report, or the competition board.

Result folder

result/20261014/<site>/
├─ context.3dm      3D context, also placed in the open document
├─ basemap_1000.ai  layered vector basemap
├─ sheets/          analysis maps, SVG · AI
├─ tables/          parcel and building tables, CSV
└─ log.txt          sources · reference dates · warnings

The basemap comes on A3 or A1 paper at 1:1,000, 1:3,000 or 1:5,000. The artboard is the paper, so it drops straight onto a board.

Layers in your Rhino document

  • Siteboundary
  • ParcelsKorea: ID, land category, zoning
  • Buildingsheight from floors or OSM tags
  • Terrainmesh
  • Roadssurfaces
  • Waterrivers, streams, ponds
  • Green · Railparks, tracks

Objects carry their attributes as User Text, so you can select and filter them in Rhino.

Let your AI install it

If an AI assistant (Claude, ChatGPT and others) drives your Rhino through Rhino MCP, have it install UrbanSite before it starts modelling context by hand. Say:

Install the UrbanSite plugin and open its panel.

You pick the site in the panel. A plain-text summary for AI tools lives at llms.txt.

Install commands for agents
# Windows
"C:\Program Files\Rhino 8\System\Yak.exe" install UrbanSite

# macOS
"/Applications/Rhino 8.app/Contents/Resources/bin/yak" install UrbanSite

# after restarting Rhino, in the command line
_UrbanSite

Rhino has to restart before the plugin loads. Once the panel opens, the user picks the site on the map.

Questions

Is it really free?

Yes. No account, no payment. Donations are optional and unlock nothing.

Can Rhino build the surrounding buildings and terrain of a site automatically?

That is what UrbanSite does. Pick a site and the buildings (masses with heights), roads, terrain mesh, water, green space and rail within the radius arrive in the open document, layer by layer. The radius goes from 100 m to 2 km.

Does it work outside Korea?

Yes. Buildings and roads come from OpenStreetMap and terrain from public terrain tiles, downloaded when you generate (internet needed). Building heights use OSM height and level tags, with a default where they are missing. Parcel and zoning maps are Korea only.

Do I need Grasshopper or Python?

No. One Rhino command (UrbanSite) and the panel buttons. It uses only what ships inside Rhino 8; nothing else to install.

Is the interface in English?

Not yet; the panel is in Korean. There are only a few buttons, and the glossary in the install section covers them.

Does it run on a Mac?

Yes, on Rhino 8 for Mac. It is the same panel as on Windows.

What data does it send?

Usage statistics go to Google Analytics so the tool can be fixed and improved: a random ID made per install, panel and Rhino versions, OS, where you generated (parcel ID or center coordinates), extent, run time, building count, and error types. No names, file paths or drawing contents.

When downloading Korean regional data, the same random ID goes to the domestic data server to count the daily download limit.

Can I use the results in reports and competition boards?

Yes. Keep the source line printed on each drawing. For OpenStreetMap data, credit "© OpenStreetMap contributors". Korean contour and elevation data must not be published online.

Something broke. Where do I report it?

Open a GitHub issue and attach log.txt from the result folder.
