Install

Quick install

Rhino’s Package Manager opens with Gorani already searched.

Install in Rhino 8 Install in Rhino 7

  1. Open Package Manager

    Type in the Rhino command line

    PackageManager

  2. Install Gorani

    Search for Gorani and press Install

  3. Restart Rhino

    The plugin loads after a restart.

  4. Open the panel

    Type in the command line

    Gorani

Quick install

Opens the Gorani page on Blender Extensions.

Install in Blender

  1. Open Get Extensions

    Menu Edit > Preferences > Get Extensions. Allow online access the first time.

  2. Install Gorani

    Search for Gorani and press Install

  3. Open the panel

    Press N in the 3D view, then Gorani > Open panel in the sidebar. The panel opens in a browser tab.

Windows

Autodesk App Store approval pending

Download for Windows

  1. Unzip

    Right-click the zip, open Properties, tick Unblock, then extract it.

  2. Move the folder

    Move the Gorani.bundle folder here. Click Continue if Windows asks for administrator permission.

    C:\Program Files\Autodesk\ApplicationPlugins

  3. Restart AutoCAD

    Gorani loads when AutoCAD starts.

  4. Open the panel

    Type in the command line

    GORANI

macOS

Autodesk App Store approval pending

Download for macOS

  1. Move the folder

    In Finder, choose Go > Go to Folder and paste this path. Move the unzipped Gorani.bundle into that folder.

    ~/Library/Application Support/Autodesk/ApplicationAddins

  2. Allow it to run

    macOS blocks programs downloaded from the internet. Run this once in Terminal to lift the block.

    xattr -dr com.apple.quarantine ~/Library/Application\ Support/Autodesk/ApplicationAddins/Gorani.bundle

  3. Restart AutoCAD

    Gorani loads when AutoCAD starts.

  4. Open the panel

    Type in the command line

    GORANI

How to use

The first run in a new area takes a little longer while it downloads data. If something breaks, check log.txt in the result folder.

  1. 1Pick a site

    Find the site on the map, or search by address or parcel number. Click parcels or draw an area to set the site.

  2. 2Make the 3D model

    Set the range and 3D options and press build. Buildings, roads, terrain and water go into your open Rhino file, layer by layer.

  3. 3Make the 2D set

    The basemap (.ai), analysis maps and tables (CSV) are saved to the result folder. Other basemap scales are one click away.

  4. 4Check the drawings

    Open any drawing large right in the panel. Change diagram colors and styles and make them again.

FAQ

Is it really free?

Yes, and no account is needed. It runs on sponsorships.

Do I need Grasshopper or other software?

No. You only need Rhino 7+, SketchUp 2022+ or Blender 4.2+, on Windows or macOS.

Does it work in Rhino 7?

Yes. The installation is the same, and PackageManager picks the Rhino 7 build. On Windows the panel opens in an Edge window, and DWG export is not available.

Where are the results saved?

The 3D model goes into the open document. Files are saved to ~/Gorani/result/site_date/: the model file, log.txt and the 2D/ folder.

Something went wrong. What should I do?

First check log.txt in the result folder. If that doesn't solve it, send us a message. Pasting the contents of log.txt helps us find the cause quickly.

[고라니] [Water deer]

The water deer (Hydropotes inermis) is a small deer native to Korea and China. Males have long tusks instead of antlers, and usually live near rivers, reed beds and wetlands.

Taxonomy 분류

The water deer belongs to the deer family and is the only living species in the genus Hydropotes. Its lack of antlers and prominent tusks distinguish it from most other deer and give it a separate genus.

Etymology 어원

The genus name Hydropotes refers to water, reflecting the animal's association with rivers and wetlands. The species name inermis means unarmed, referring to the absence of antlers.
