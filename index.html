지원 프로그램

Gorani는 라이노, 스케치업, 블렌더 유저를 위한 무료 오픈소스 플러그인입니다.

  • Rhino8 이상
  • SketchUp2022 이상
  • Blender4.2 이상
  • Archicad
  • Windows · macOS지원 운영체제

설치

  1. 패키지 매니저 열기

    Rhino 명령창에 입력

    PackageManager

  2. Gorani 설치

    검색칸에 Gorani를 넣고 설치

  3. Rhino 다시 시작

    다시 켜야 플러그인이 올라옵니다.

  4. 패널 열기

    명령창에 입력

    Gorani

  1. Extension Warehouse 열기

    메뉴 확장 > Extension Warehouse

  2. Gorani 설치

    Gorani를 검색하고 설치

  3. 패널 열기

    메뉴 확장 > Gorani, 또는 도구 막대의 고라니 단추

  1. Get Extensions 열기

    메뉴 Edit > Preferences > Get Extensions. 처음이면 온라인 접근을 허용합니다.

  2. Gorani 설치

    Gorani를 검색하고 Install

  3. 패널 열기

    3D 뷰에서 N을 눌러 사이드바 Gorani > 패널 열기. 패널은 브라우저 탭으로 열립니다.

사용법

처음 쓰는 지역은 데이터를 받느라 시간이 조금 더 걸립니다. 문제가 생기면 결과 폴더의 log.txt를 확인해 주세요.

  1. 1대상지 고르기

    지도에서 직접 대상지를 찾거나, 주소와 지번으로 검색합니다. 필지를 누르거나 구역을 그려 대상지를 정합니다.

  2. 23D 모델 만들기

    범위와 3D 옵션을 정하고 만들기를 누르면, 건물과 도로, 지형, 하천이 열려 있는 Rhino 문서에 레이어별로 들어옵니다.

  3. 32D 자료 만들기

    베이스맵(.ai)과 현황도, 분석도, 조서(CSV)를 결과 폴더에 저장합니다. 다른 축척 베이스맵도 바로 받을 수 있습니다.

  4. 4도면 확인하기

    만든 도면은 패널에서 바로 크게 미리 봅니다. 다이어그램 색과 스타일도 바꿔 다시 만들 수 있습니다.

지원 지역

국내 전국

공공 데이터로 필지와 건물, 지형, 용도지역까지 만듭니다. 시군구별 데이터는 패널에서 한 번 받아 둡니다.

  • 지적, 건물(층수·용도·사용승인일)
  • 1:5,000 등고선과 표고점 지형
  • 용도지역, 도형-배경도, 토지이용 등 분석도

해외

생성할 때 인터넷에서 받아 만듭니다. 필지와 용도지역 도면은 국내만 됩니다. 일본은 PLATEAU 건물과 국토지리원(GSI) 지형, 네덜란드는 Kadaster 3D Basisvoorziening, 프랑스는 IGN BD TOPO 건물(실측 높이)을 씁니다.

  • OpenStreetMap 건물과 도로
  • 공개 지형 타일
  • 반경 100 m에서 2 km까지

리뷰 남기기

정말 무료인가요?

네. 계정도 필요 없습니다. 후원으로 운영합니다.

Grasshopper나 다른 프로그램이 필요한가요?

아니요. Rhino 8, SketchUp 2022 이상, Blender 4.2 이상 중 하나만 있으면 됩니다. Windows와 macOS에서 작동합니다.

결과물은 어디에 저장되나요?

3D 모델은 열려 있는 문서에 들어가고, 파일은 ~/Gorani/result/대상지_날짜/에 모델 파일, log.txt, 2D/ 폴더로 저장됩니다.

문제가 생기면 어떻게 하나요?

먼저 결과 폴더의 log.txt를 확인해 주세요. 해결되지 않으면 GitHub Issues에 log.txt를 첨부해 남겨 주세요.

[고라니] [Water deer]

고라니 (Hydropotes inermis)는 한국과 중국에 분포하는 작은 사슴이다. 수컷은 뿔 대신 길게 자란 송곳니를 가지고 있으며, 강과 하천 주변의 물가와 습지에서 주로 살아간다.

분류 Taxonomy

고라니는 사슴과에 속하며, 고라니속(Hydropotes)을 이루는 유일한 현존 종이다. 겉모습은 작은 사슴과 비슷하지만 뿔이 없고 송곳니가 발달한 독특한 형태 때문에 별도의 속으로 분류된다.

어원 Etymology

학명 Hydropotes는 물을 뜻하는 말에서 유래했으며, 물가와 습지에 가까이 사는 생태적 특징을 가리킨다. 종명 inermis는 무장하지 않았다는 뜻으로, 뿔이 없는 특징과 관련된다.
