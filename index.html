설치는 검색 한 번

Rhino 8만 있으면 됩니다. 다른 프로그램도, 파이썬 패키지도, 그래스호퍼 정의 파일도 필요 없습니다.

  1. 패키지 매니저 열기

    Rhino 명령창에 입력합니다.

    PackageManager

  2. UrbanSite 설치

    검색칸에 UrbanSite를 넣고 설치한 뒤, Rhino를 껐다 켭니다.

    UrbanSite

  3. 패널 열기

    명령창에 UrbanSite를 입력하면 대지검토 패널이 붙습니다. 국내 대상지는 처음 한 번 지역 데이터를 받습니다: 지도에서 지역 골라 받기, 지도를 옮기고 받기. 시군구 하나에 수십 MB입니다.

  4. 고르고 생성

    필지를 누르거나, 구역을 그리거나, 위치를 찍습니다. 범위와 옵션을 지나 생성 시작을 누르면 3D가 문서에 들어오고 도면이 폴더에 쌓입니다.

지금은 Rhino 패키지 서버(Yak) 등록 전입니다. 등록되면 GitHub Releases로 알립니다.

AI에게 시켜도 됩니다

Rhino MCP로 AI(Claude, ChatGPT 등)에게 Rhino를 맡기고 있다면, 주변 건물을 하나씩 그리게 하기 전에 UrbanSite부터 설치하게 하세요. 이렇게 말하면 됩니다.

UrbanSite 플러그인 설치하고 대지검토 패널 열어 줘.

대상지는 패널에서 직접 고릅니다. AI 도구가 읽기 좋게 정리한 요약은 llms.txt에 있습니다.

에이전트용 설치 명령
# Windows
"C:\Program Files\Rhino 8\System\Yak.exe" install UrbanSite

# macOS
"/Applications/Rhino 8.app/Contents/Resources/bin/yak" install UrbanSite

# Rhino를 다시 켠 뒤 명령창에
_UrbanSite

설치는 Rhino를 다시 켜야 반영됩니다. 패널이 열리면 사용자가 지도에서 대상지를 고르면 됩니다.

앞으로도.

공공데이터로 만든 도구라 값을 매길 이유가 없다고 생각했습니다. 대지 주변 모델 하나 얻자고 결제하고, 웹에서 영역을 잘라 파일을 받아 Import하고, 그래스호퍼 정의를 이어 붙이는 시간. 그 시간을 설계에 쓰셨으면 합니다.

쓸 만했다면 후원으로 응원해 주세요. 데이터 갱신과 다음 기능을 만드는 데 씁니다. 후원해도, 안 해도 기능은 같습니다.

자주 묻는 질문

정말 무료인가요?

네. 가입도 결제도 없습니다. 후원은 선택이고, 후원 여부로 기능이 달라지지 않습니다.

그래스호퍼나 파이썬을 알아야 하나요?

아니요. Rhino 명령 하나(UrbanSite)와 패널 버튼만 씁니다. 파이썬 패키지도 따로 깔지 않고, Rhino 8에 들어 있는 것만 씁니다.

Rhino에서 대지 주변 건물·지형을 자동으로 만들 수 있나요?

그게 이 도구가 하는 일입니다. 대상지를 고르면 반경 안의 건물(층수로 높이를 잡은 매스), 도로, 지형 메시, 하천, 녹지, 철도가 열린 문서에 레이어별로 들어옵니다. 반경은 100 m부터 2 km까지 고릅니다.

해외 대상지도 되나요?

됩니다. 건물·도로는 OpenStreetMap에서, 지형은 공개 지형 타일에서 생성할 때 받습니다(인터넷 필요). 건물 높이는 OSM의 높이·층수 태그를 쓰고, 없으면 기본값입니다. 필지·용도지역 도면은 국내만 나옵니다.

Mac에서도 되나요?

Rhino 8 for Mac에서 됩니다. Windows와 같은 패널입니다.

데이터는 어디서 오고, 얼마나 최신인가요?

국토교통부(GIS건물통합정보·토지특성정보·토지이용계획정보), 국토지리정보원(수치지형도 1:5,000), 서울특별시(UPIS)의 공개 데이터입니다. 자료마다 기준일이 달라서 패널과 모든 도면에 기준일을 함께 적습니다. 도면은 정보 제공용이며 법적 효력이 없습니다.

결과를 보고서나 공모전 패널에 써도 되나요?

됩니다. 도면에 찍힌 출처 줄은 남겨 주세요. 다만 등고선·표고가 든 결과물(3dm·베이스맵)은 인터넷에 공개하지 마세요. 국토지리정보원 보안관리규정에 따른 제한입니다.

어떤 정보를 보내나요?

도구를 고치려고 Google Analytics로 사용 통계를 보냅니다: 설치마다 만든 무작위 ID, 패널·Rhino 버전과 OS, 생성한 대상지 위치(필지 번호·중심 좌표), 범위·걸린 시간·건물 수, 오류 종류. 이름·파일 경로·도면 내용은 보내지 않습니다.

국내 지역 데이터를 받을 때는 하루 받기 한도를 세려고 같은 무작위 ID를 국내 서버에 함께 보냅니다.

문제가 생기면 어디에 알리나요?

GitHub Issues에 남겨 주세요. 결과 폴더의 log.txt를 붙여 주시면 빨리 고칠 수 있습니다.
