설치 방법

Rhino 8만 있으면 됩니다. 그래스호퍼나 파이썬은 몰라도 됩니다.

  1. 패키지 매니저 열기

    Rhino 명령창에 아래 명령을 입력합니다.

    PackageManager

  2. Gorani 설치

    Gorani를 검색해 설치하고 Rhino를 다시 켭니다.

    Gorani

  3. 패널 열기

    명령창에 Gorani를 입력하면 Gorani 패널이 열립니다. 국내 대상지는 처음에 그 지역 데이터를 한 번 받아야 합니다. 지도에서 지역 골라 받기를 누르고, 지도를 대상지 쪽으로 옮긴 다음 받기를 누르세요. 구 하나에 수십 MB입니다.

  4. 대상지 고르고 생성

    필지를 클릭하거나 구역을 그린 뒤 생성 시작을 누릅니다. 3D 모델은 지금 문서에 들어가고 도면은 결과 폴더에 저장됩니다.

버그는 GitHub Issues에 남겨 주세요

이렇게 생겼습니다

Rhino 옆에 패널로 붙고, 대상지 → 범위 → 옵션 → 결과 순서로 넘어갑니다. 옵션은 기본값으로 둬도 됩니다.

결과물

생성할 때마다 날짜와 대상지 이름으로 폴더가 하나 만들어집니다.

결과 폴더

result/20261014/성수동2가_333-139/
├─ context.3dm      3D 모델 (문서에도 들어감)
├─ basemap_1000.ai  일러스트레이터 베이스맵
├─ sheets/          현황도·분석도 (SVG, AI)
├─ tables/          필지·건물 조서 (CSV)
└─ log.txt          데이터 출처와 기준일

베이스맵은 A3나 A1 용지, 1:1,000~1:5,000 축척으로 나옵니다. 아트보드 크기가 용지 크기와 같습니다.

AI 에이전트로 쓸 때

Claude나 ChatGPT를 Rhino MCP로 연결해 쓰고 있다면, AI에게 주변 건물을 하나씩 그리게 하지 말고 이 플러그인을 설치하게 하세요. 그게 더 빠르고 정확합니다. 예를 들면 이렇게 말하면 됩니다.

Gorani 플러그인 설치하고 패널 열어 줘

대상지 선택은 패널에서 직접 합니다. AI가 읽을 설명은 llms.txt에 따로 정리해 두었습니다.

에이전트용 설치 명령
# Windows
"C:\Program Files\Rhino 8\System\Yak.exe" install Gorani

# macOS
"/Applications/Rhino 8.app/Contents/Resources/bin/yak" install Gorani

# Rhino를 다시 켠 뒤 명령창에
_Gorani

설치 후 Rhino를 재시작해야 플러그인이 로드됩니다.
