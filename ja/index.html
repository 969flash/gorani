3D地形とダイアグラムを、すばやく作成

Goraniは、Rhino・SketchUp・Blenderユーザーのための無料オープンソースプラグインです。

3Dモデル

周辺の文脈をレイヤー別に

建物、道路、地形、水系が、開いているドキュメントにレイヤー別に入ります。レイヤーパネルで結果の表示・非表示を切り替えられます。

  • 建物
  • 道路
  • 地形
  • 水系
  • 緑地
  • 鉄道
  • 区画
2D資料

敷地分析で徹夜しない

図と地、用途地域、土地利用現況など22種類のダイアグラムを、編集できるSVGで提供します。色やスタイルも変えられます。

  • ベースマップbasemap_縮尺.ai
  • 現況図・分析図sheets/*.svg, .ai
  • 区画・建物調書tables/*.csv

インストール

すぐにインストール

RhinoのパッケージマネージャーがGoraniの検索結果で開きます。

  • Rhino 8 Gorani 0.3.7
  • Rhino 7 Gorani 0.3.7

  1. パッケージマネージャーを開く

    Rhinoのコマンドラインに入力

    PackageManager

  2. Goraniをインストール

    Goraniを検索してインストールを押す

  3. Rhinoを再起動

    再起動するとプラグインが読み込まれます。

  4. パネルを開く

    コマンドラインに入力

    Gorani

すぐにインストール

Extension Warehouseの承認待ち

  • SketchUp Gorani 0.3.7

  1. 拡張機能マネージャーを開く

    メニュー 拡張機能 > 拡張機能マネージャー

  2. Goraniをインストール

    拡張機能をインストールを押し、ダウンロードした.rbzファイルを選んではいを押す

  3. パネルを開く

    メニュー 拡張機能 > Gorani、またはツールバーのGoraniボタン

すぐにインストール

Blender ExtensionsのGoraniページを開きます。

  • Blender Gorani

  1. Get Extensionsを開く

    メニュー Edit > Preferences > Get Extensions。初回はオンラインアクセスを許可します。

  2. Goraniをインストール

    Goraniを検索してInstallを押す

  3. パネルを開く

    3DビューでNキーを押し、サイドバーのGorani > Open panelを選びます。パネルはブラウザのタブで開きます。

すぐにインストール

Autodesk App Storeの承認待ち

  • Windows Gorani 0.3.6

  1. 展開する

    zipを右クリックし、プロパティで許可するにチェックしてから展開する

  2. フォルダーを移動

    Gorani.bundleフォルダーをこの場所へ移動する。管理者の許可を求められたら続行

    C:\Program Files\Autodesk\ApplicationPlugins

  3. AutoCADを再起動

  4. パネルを開く

    コマンドラインに入力

    Gorani

すぐにインストール

Autodesk App Storeの承認待ち

  • macOS Gorani 0.3.6

  1. フォルダーを移動

    Finderの移動 > フォルダへ移動にこのパスを貼り付け、開いたフォルダーへ展開したGorani.bundleを移動する

    ~/Library/Application Support/Autodesk/ApplicationAddins

  2. 実行を許可

    インターネットから入手したプログラムはmacOSがブロックするため、ターミナルで一度実行して解除する

    xattr -dr com.apple.quarantine ~/Library/Application\ Support/Autodesk/ApplicationAddins/Gorani.bundle

  3. AutoCADを再起動

  4. パネルを開く

    コマンドラインに入力

    Gorani

使い方

初めての地域では、データのダウンロードに少し時間がかかります。問題があれば、結果フォルダのlog.txtを確認してください。

  1. 1対象地を選ぶ

    地図で対象地を探すか、住所や地番で検索します。区画をクリックするか、エリアを描いて対象地を決めます。

  2. 23Dモデルを作る

    範囲と3Dオプションを決めて作成を押すと、建物、道路、地形、水系が開いているRhinoファイルにレイヤー別に入ります。

  3. 32D資料を作る

    ベースマップ（.ai）、現況図、分析図、調書（CSV）を結果フォルダに保存します。別の縮尺のベースマップもすぐに作れます。

  4. 4図面を確認する

    作成した図面はパネルですぐに大きくプレビューできます。ダイアグラムの色やスタイルを変えて作り直すこともできます。

よくある質問

本当に無料ですか？

はい。アカウントも不要です。支援によって運営しています。

Grasshopperやほかのソフトは必要ですか？

いいえ。Rhino 7以降、SketchUp 2022以降、Blender 4.2以降のいずれかがあれば使えます。WindowsとmacOSで動作します。

Rhino 7 でも動きますか？

はい。インストール方法は同じで、PackageManager が Rhino 7 向けを自動で選びます。Windows ではパネルが Edge ウィンドウで開き、DWG 保存はできません。

結果はどこに保存されますか？

3Dモデルは開いているドキュメントに入り、ファイルは~/Gorani/result/対象地_日付/にモデルファイル、log.txt、2D/フォルダとして保存されます。

問題が起きたらどうすればいいですか？

まず結果フォルダのlog.txtを確認してください。解決しない場合はお問い合わせください。log.txtの内容を貼り付けていただくと、原因をすぐに確認できます。

[고라니] [キバノロ]

キバノロ（Hydropotes inermis）は、朝鮮半島と中国に分布する小型のシカ。オスは角の代わりに長く伸びた牙を持ち、川や湿地の近くに多くすむ。

分類 Taxonomy

シカ科に属し、キバノロ属（Hydropotes）の唯一の現生種である。角がなく牙が発達した独特の姿から、独立した属に分類される。

語源 Etymology

属名Hydropotesは水を意味する語に由来し、川や湿地の近くにすむ生態を表す。種小名inermisは「武装していない」という意味で、角がないことにちなむ。
