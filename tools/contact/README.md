# 문의 받기 (구글 시트 + 앱스 스크립트)

웹사이트 문의 폼 → 앱스 스크립트 웹 앱 → 구글 시트에 한 줄 + 알림 메일.
서버·유료 서비스 없이 개발용 구글 계정 하나로 돌린다. 앱이 늘어도 시트 하나에서 탭과 `앱` 칸으로 나눠 본다.

## 처음 설정(한 번, 약 10분)

1. 개발용 구글 계정으로 새 구글 시트를 만든다. 이름 예: `문의함`.
2. 시트 메뉴 **확장 프로그램 > Apps Script** → 기본 `Code.gs` 내용을 이 폴더의 `Code.gs`로 바꾸고 저장.
3. 편집기 위 함수 목록에서 `setup`을 골라 **실행** → 권한 승인(시트·메일·외부 요청). 시트에 `Gorani 웹` 탭이 생긴다.
4. (선택) **프로젝트 설정 > 스크립트 속성**에 `NOTIFY_EMAIL` = 알림 받을 주소. 쉼표로 여러 개. 비우면 이 계정으로 온다.
5. **배포 > 새 배포 > 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**(익명 방문자가 보내야 하므로)
   - 배포 → 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사.
6. 웹사이트 `assets/site.js` 맨 위 `CONTACT_URL = ""`에 그 URL을 넣고 배포한다.
7. 브라우저로 URL을 열어 `{"ok":true,"apps":["gorani-web"]}`가 보이면 살아 있다. 사이트에서 시험 문의를 하나 보내 시트·메일을 확인한다.

코드를 고친 뒤에는 **배포 > 배포 관리 > 수정(연필) > 버전: 새 버전**으로 같은 URL을 유지한다. "새 배포"를 하면 URL이 바뀐다.

## 시트 칸

| 칸 | 누가 | 뜻 |
|---|---|---|
| 문의 번호 | 자동 | `GW-261030-001` (앱 머리·날짜·순번). 메일 제목에도 붙는다 |
| 받은 시각·앱·주제·이름·이메일·내용·언어·페이지 | 자동 | 폼에서 온 값. 주제는 한국어로 적힌다 |
| 상태 | 사람 | `새 문의` → `확인 중` → `답장함` → `완료`, 광고·장난은 `스팸`. 색이 바뀐다 |
| 담당 | 사람 | Hoon / Cho |
| 메모 | 사람 | 처리 내용, 연결한 GitHub 이슈 번호 |
| 답장한 날 | 사람 | 답장한 날짜(`Ctrl/⌘ + ;`) |

## 운영 규칙(제안)

- **알림 → 답장**: 알림 메일의 [답장]을 누르면 문의한 사람에게 바로 간다(reply-to). 답장 뒤 시트 상태를 `답장함`으로.
- **주 1회 정리**: 필터 `상태 = 새 문의·확인 중`으로 밀린 것을 본다. 목표는 영업일 3일 안 첫 답장.
- **오류 신고**: 재현되면 GitHub 이슈(공개)로 옮기고 메모에 이슈 번호. 이슈에는 이름·메일을 쓰지 않는다.
- **지역·데이터 요청**: 나라별로 모아 두었다가 데이터 추가 우선순위에 쓴다(시트 필터 `주제`).
- **자동 답장은 보내지 않는다**: 남의 메일 주소로 우리 메일을 보내게 하는 스팸 통로가 되기 때문.
- **개인정보**: 폼에 적은 대로 답장 후 1년이 지나면 그 줄을 지운다(분기마다 `답장한 날` 기준 정리). 시트 공유는 운영자 둘만.

## 스팸·한도

- 폼: 사람에게 안 보이는 칸(채워 오면 봇), 3초 안에 보낸 것은 저장하지 않고 성공처럼 보인다.
- 스크립트: 같은 메일은 1분에 한 번, 전체 시간당 60건까지. 넘치면 폼에 "보내지 못했습니다"가 뜬다.
- 무료 구글 계정의 메일 보내기 한도는 하루 약 100통이다. 문의가 그보다 많아지면 알림을 하루 요약으로 바꾼다.
- 스팸이 많아지면 Cloudflare Turnstile(무료 캡차)을 폼과 스크립트에 붙인다.

## 새 앱 붙이기

1. `Code.gs`의 `APPS`에 한 줄: `'gorani-plugin': ['Gorani 플러그인', 'GP'],`
2. 저장 → `setup` 실행(새 탭) → 배포 관리에서 새 버전.
3. 그 앱은 같은 URL로 `{"app": "gorani-plugin", "name", "email", "topic", "message", "lang", "page", "elapsed"}`를 `text/plain` POST로 보낸다.
