安装

快速安装

Rhino 的 Package Manager 会打开并显示 Gorani 的搜索结果。

  • Rhino 8 Gorani 0.3.7
  • Rhino 7 Gorani 0.3.7

  1. 打开 Package Manager

    在 Rhino 命令行中输入

    PackageManager

  2. 安装 Gorani

    搜索 Gorani 并点击安装

  3. 重启 Rhino

    重启后插件才会加载。

  4. 打开面板

    在命令行中输入

    Gorani

快速安装

等待 Extension Warehouse 批准

  • SketchUp Gorani 0.3.7

  1. 打开扩展程序管理器

    菜单 扩展程序 > 扩展程序管理器

  2. 安装 Gorani

    点击安装扩展程序，选择下载的 .rbz 文件，在确认窗口中点击是

  3. 打开面板

    菜单 扩展程序 > Gorani，或工具栏上的 Gorani 按钮

快速安装

打开 Blender Extensions 上的 Gorani 页面。

  • Blender Gorani

  1. 打开 Get Extensions

    菜单 Edit > Preferences > Get Extensions。首次使用需允许联网访问。

  2. 安装 Gorani

    搜索 Gorani 并点击Install

  3. 打开面板

    在3D视图中按 N，然后在侧边栏选择Gorani > Open panel。面板会在浏览器标签页中打开。

快速安装

等待 Autodesk App Store 批准

  • Windows Gorani 0.3.6

  1. 解压

    右键单击 zip 文件，在属性中勾选解除锁定后再解压

  2. 移动文件夹

    把 Gorani.bundle 文件夹移到下面的位置。如果要求管理员权限，点击继续

    C:\Program Files\Autodesk\ApplicationPlugins

  3. 重启 AutoCAD

  4. 打开面板

    在命令行中输入

    Gorani

快速安装

等待 Autodesk App Store 批准

  • macOS Gorani 0.3.6

  1. 移动文件夹

    在访达中打开前往 > 前往文件夹，粘贴下面的路径，把解压后的 Gorani.bundle 移到打开的文件夹中

    ~/Library/Application Support/Autodesk/ApplicationAddins

  2. 允许运行

    macOS 会阻止从网上下载的程序运行。在终端中执行一次下面的命令即可解除

    xattr -dr com.apple.quarantine ~/Library/Application\ Support/Autodesk/ApplicationAddins/Gorani.bundle

  3. 重启 AutoCAD

  4. 打开面板

    在命令行中输入

    Gorani

使用方法

首次使用某个地区时，需要下载数据，会稍慢一些。如果出现问题，请查看结果文件夹中的 log.txt。

  1. 1选择场地

    在地图上查找场地，或按地址、地块编号搜索。点击地块或绘制区域来确定场地。

  2. 2生成3D模型

    设置范围和3D选项后点击生成，建筑、道路、地形和水系会按图层放入当前打开的 Rhino 文件。

  3. 3生成2D资料

    底图（.ai）、现状图、分析图和统计表（CSV）会保存到结果文件夹。也可以立即生成其他比例尺的底图。

  4. 4查看图纸

    生成的图纸可以直接在面板中放大预览。也可以更改图表颜色和样式后重新生成。

常见问题

真的免费吗？

是的，也不需要注册账号。项目依靠赞助运营。

需要 Grasshopper 或其他软件吗？

不需要。只要有 Rhino 7 及以上、SketchUp 2022 及以上或 Blender 4.2 及以上中的一个即可，支持 Windows 和 macOS。

Rhino 7 能用吗？

可以。安装方法相同，PackageManager 会自动选择 Rhino 7 版本。在 Windows 上，面板会在 Edge 窗口中打开，并且不支持保存 DWG。

结果保存在哪里？

3D模型会放入当前打开的文件，文件保存在 ~/Gorani/result/场地_日期/，包括模型文件、log.txt 和 2D/ 文件夹。

出现问题怎么办？

请先查看结果文件夹中的 log.txt。如果仍未解决，请在 GitHub Issues 提交问题并附上 log.txt。没有 GitHub 账号的话，也可以使用下方的联系表单。

[고라니] [獐]

獐（Hydropotes inermis）是分布于朝鲜半岛和中国的小型鹿类。雄性没有鹿角，而是长有长长的獠牙，多栖息在河流和湿地附近。

分类 Taxonomy

獐属于鹿科，是獐属（Hydropotes）唯一的现存物种。由于没有鹿角、獠牙发达，形态独特，被单独列为一属。

词源 Etymology

属名 Hydropotes 源自表示“水”的词，指其栖息于河流和湿地附近的习性。种名 inermis 意为“无武装”，指其没有鹿角。
